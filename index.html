🐙 GitHub Pages Setup — Free Forever (5 min)
1
Create a free GitHub account
Go to github.com → Sign up (free) → Verify email.
2
Create a new repository
Click + → New repository, name it portfolio, set to Public, tick ✅ Add a README file, then Create repository.
3
Upload the dashboard file
In repo → Add file → Upload files → drag index.html → Commit changes.
4
Enable GitHub Pages
Settings → Pages → Source: Deploy from branch → Branch: main / (root) → Save.
5
Get your permanent URL
Wait ~60s → your URL: https://YourUsername.github.io/portfolio — bookmark it!
6
Add to phone home screen
Chrome: ⋮ → Add to Home screen. Safari: Share → Add to Home Screen. ✅ Works like a native app!
📅 Daily Portfolio Update (2 taps)
1
Export CSV from your broker
Login → Portfolio → Unrealised P&L → Export CSV → Save to Downloads.
2
Tap "📂 Update CSV"
Select the CSV → Dashboard instantly recalculates with new quantities and prices.
3
Tap "↻ Live" for real-time prices
Fetches all NSE prices in 1–2 fast batch calls (vs 30+ slow ones before). Auto-refreshes every 5 min.
🔒 100% Private: CSV is read entirely in your browser — your data never leaves your device.
💡 Export Tip: Use the ⬇ Export CSV button in Holdings tab to download a shareable report with live P&L data. Opens perfectly in Excel.
