🐙 GitHub Pages Setup — Free Forever (5 min)
1
Create a free GitHub account
Go to github.com → Sign up (free) → Verify email. If you already have one, just sign in.
2
Create a new repository
Click + (top right) → New repository
Name it: portfolio   (or any name you like)
Set to Public (required for free Pages)
Tick ✅ Add a README file
Click Create repository
3
Upload the dashboard file
In your new repo → click Add file → Upload files
Drag the downloaded portfolio_dashboard.html file
⚠️ RENAME IT to exactly index.html before uploading
    (Right-click the file → Rename → index.html)
Add commit message: "Initial upload" → Click Commit changes
4
Enable GitHub Pages
In your repo → Settings tab (top menu)
Scroll down to Pages (left sidebar)
Under Source → select Deploy from a branch
Branch: main → Folder: / (root)
Click Save
5
Get your permanent URL
Wait ~60 seconds → refresh Settings → Pages
Your URL appears: https://YourUsername.github.io/portfolio
✅ Copy this URL — this is your permanent dashboard link!
6
Add to phone home screen
Open URL on phone Chrome → tap ⋮ menu → Add to Home screen
On Safari (iPhone) → tap Share → Add to Home Screen
✅ Icon appears on home screen — one tap to open, works like an app!
📅 When you update the dashboard file later
A
Go to your GitHub repo
Visit github.com/YourUsername/portfolio → click on index.html
B
Replace the file
Click the ✏️ pencil edit icon → delete all content → paste new file content → Commit changes. Site updates in ~30 seconds.
📅 Daily Portfolio Update (2 taps from phone)
1
Export CSV from your broker
Login → Portfolio → Unrealised P&L → Export CSV → Save to phone Downloads
2
Tap "📂 Update CSV" button (top right)
Select the CSV → Dashboard instantly recalculates. New stocks appear, sold ones disappear, quantities update. Zero manual work.
3
Tap "↻ Live" for real-time prices
Fetches NSE live prices. CMP column and P&L update in real time. Auto-refreshes every 5 minutes while the page is open.
🔒 100% Private: Your CSV is read entirely in your browser. It never goes to any server. GitHub only hosts the HTML file — your portfolio data never leaves your device.
💡 Tip: If you get a new CSV from your broker, you don't need to update GitHub. Just open the site and tap "📂 Update CSV" — it reads from your phone locally each time.
